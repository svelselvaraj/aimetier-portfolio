Read the component map

Hyperclip and the operator console reach the web API through the gateway. WebSocket (WS) carries live updates. Row-level security (RLS) scopes database access. PostgreSQL holds tenant-scoped work and wakes the leader worker. The worker dispatches a run, and the controller provisions isolated compute. Runtime adapters invoke models and approved tools. The browser has a separate session and outbound proxy. Object storage holds durable files and session state.

Engineering decisions

Where the platform draws the line

Context belongs to a tenant
Access rules filter memory and documents before retrieval ranks them. Database row-level policies enforce the company boundary, which cross-company tests exercise.
The worker owns orchestration
PostgreSQL signals work across the web and worker tiers. The runner gets a scoped workspace. On Kubernetes, a separate controller holds the credential to create pods.
Model choice belongs to the workspace
Each company sets its adapter order and model groups. If the primary adapter fails, the policy can select a fallback in the same group. The task keeps its owner, budget and review rules.
“Done” requires evidence
The server derives the result from checks attached to the run. Offline evaluation also tests protected groups of cases by role, so an overall average cannot hide a reviewer regression.
Measure the operator’s wait
Time to first visible progress, cold-start duration and warm-runner misses guide latency triage. Run events connect what the operator saw with what the worker did.
Keep cloud dependencies explicit
AWS is the documented reference deployment. Azure and Google Cloud Terraform definitions describe alternative infrastructure. The storage interface has S3 and Azure Blob implementations.
