Architecture

What makes the run possible

⇄

Model and provider adapters

A common runtime interface dispatches runs across supported model providers and collects usage and cost events.

→

Agent coordination

Roles and task ownership define who does the work. Scheduled and event-driven workers dispatch tasks and support agent-to-agent handoffs (A2A).

≋

Conversation and memory

Threads capture user context. PostgreSQL and pgvector support semantic recall across runs, scoped to the agent by default.

⌘

Tools and skills

Configured tools give agents access to approved services, including integrations through the Model Context Protocol (MCP). Reusable skills carry task instructions across runs.

✓

Evaluation and approvals

Rubrics guide peer review. The server requires evidence tied to the run before completion, and workflows can pause for human approval.

◇

Operational controls

Scoped budgets set warning and hard-stop thresholds. Audit records and company-level data boundaries support oversight.
